# M1+ Music Navidrome 1.3.0

Unofficial Shanling M1 Plus firmware based on [imfing/m1plus-music 1.3.0](https://github.com/imfing/m1plus-music), retaining its upstream features, including Tidal, and adding Navidrome/Subsonic integration and Sample Rate RGB. See the repository [acknowledgements](../../README.md#acknowledgements) for credit.

## Upstream M1+ Music features retained

- 10-band EQ, AutoEq downloads, presets and separate output EQ.
- WPA3 and Enhanced Open Wi-Fi, redesigned Wi-Fi Transfer, Podcast Discover, library menus, Favorite and Get Info.
- Existing Cover Flow, iPod mode, Podcasts, Radio, Cassette and Vinyl modes, and other library and playback features.

## Navidrome and Subsonic

- Save server URL, username and password on the SD card and reconnect using those settings. HTTP and HTTPS are supported; HTTP sends credentials and audio without encryption, so use it only on a trusted network.
- Sync a paged metadata index, confirm manual refreshes, browse Songs and DSD Downloads, and search the server catalog. The index is capped at 100,000 tracks; exceeding the cap keeps the prior index and reports the limit.
- Stream supported tracks over Wi-Fi through the Subsonic raw-audio endpoint, without requesting server transcoding. Download tracks to SD with visible progress, resume support where HTTP ranges are supported, and a 32 MiB free-space reserve.
- Browse server tracks in Songs, Albums, Artists, Album Artists, Genres and Composers, global search, Cover Flow and the virtual iPod. Mixed queues preserve the current view's order. Un-downloaded DSD tracks are excluded from stream queues and virtual library views.
- Mark only server-streamed tracks with a small green dot. Local copies and downloaded tracks take precedence in Libraries and have no stream marker; the Navidrome page continues to show the full server catalog.
- Reuse the player's artwork cache for Navidrome and Now Playing. Server albums can appear in Cover Flow and Pod mode with artwork.
- Download DSD files explicitly from the DSD Downloads section. They are never streamed; a successful DSD download starts a background SD-library refresh so the file becomes locally playable.
- Keep the interface aligned with the stock theme, with grid/list views, alphabet navigation, server status, and track download progress.

## Sample Rate RGB

Extras > Settings > System includes a persistent **Sample Rate RGB** switch. While a track plays, the lamp mixes channels according to the playback format:

| Format | Red | Green | Blue |
|---|---:|---:|---:|
| Lossy audio, or PCM at 16-bit/44.1 kHz and below | 100% | 0% | 0% |
| PCM above 16-bit through 44.1 kHz; DSD64 | 60% | 0% | 40% |
| PCM above 44.1 kHz through 48 kHz | 20% | 0% | 80% |
| PCM above 48 kHz through 88.2 kHz | 0% | 0% | 100% |
| PCM above 88.2 kHz and below 176.4 kHz; DSD128 | 0% | 20% | 80% |
| PCM from 176.4 kHz to below 192 kHz; DSD256 | 0% | 40% | 60% |
| PCM at 192 kHz and above (24-bit or higher); DSD512 and above | 0% | 100% | 0% |

Volume scales overall lamp intensity without changing the target channel ratios. The indicator reads playback metadata and volume but does not read or modify PCM samples, volume settings, decoder settings or DAC settings. Turning it off restores Shanling's saved lamp behavior.

## Limits and safety

- DSD/DSF/DFF streaming is not supported. Download these files first; regular supported tracks can stream or download.
- Offline listening requires downloaded files. The synced server index is a snapshot and must be synced again to refresh metadata.
- Server streaming is limited to 64 queued tracks; mixed library queues are limited to 4,096 entries. Artwork caching is bounded and may leave covers unavailable when images fail validation or exceed cache limits.
- Raw streaming avoids client-side transcoding, but does not by itself prove sample-for-sample output at the DAC across every server and format.
- The package uses the existing update path and does not modify bootloader or recovery code. The stock rootfs image-size limit is enforced by the build. Firmware installation still carries device risk: verify the checksum, back up the card, keep the player charged, and do not interrupt the update.

## Install

Download `update.bin` and `SHA256SUMS` from the GitHub release, verify the checksum, copy `update.bin` to the TF card, then choose **System Update → TF card update** on the player. See the [installation guide](../install.md) for details. This unofficial firmware is installed at your own risk; I am not responsible for damage caused by installing or using it.
